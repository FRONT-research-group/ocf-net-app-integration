# O-NEF upstream provenance

This directory contains a sanitized snapshot of the complete O-NEF system
included as part of the CEF/O-NEF migration work.

Upstream repository:
https://github.com/FRONT-research-group/O-NEF

Imported revision:
1656a2f68162b5359900dae743e24cf74009fcad

Upstream tag:
v2.2.3

The upstream O-NEF repository remains authoritative for its original Git
history and authorship.

For this imported snapshot, literal deployment credentials and Mapbox access
tokens present in the upstream source were replaced with placeholders before
the files were added to this repository.
